🏥 Insurance Data Analysis with Exploratory Data Analysis (EDA)

📌 Project Overview

This project performs **Exploratory Data Analysis (EDA)** on an Insurance Charges dataset to identify the factors affecting medical insurance costs. The analysis includes data cleaning, preprocessing, visualization, feature engineering, and statistical analysis using Python.

The objective is to gain meaningful insights into how variables such as age, BMI, smoking status, gender, number of children, and region influence insurance charges.

## 💡 Business Insights

- Smoking significantly increases insurance premiums.
- BMI is an important predictor of healthcare expenses.
- Age positively influences medical costs.
- Lifestyle factors contribute more than geographical location.
- Insurance companies can utilize these insights for premium pricing and risk assessment.

## 🔍 Key Insights

### Age

- Older individuals generally have higher insurance charges.

### Smoking

- Smokers incur significantly higher insurance costs than non-smokers.

### BMI

- Higher BMI is associated with increased insurance expenses.

### Gender

- Gender has minimal impact on insurance charges.

### Region

- Insurance costs show slight regional variations.

### Children

- Number of children has a relatively small influence on insurance charges.
